# Image Recovery Script (Statamic)

## Background

After the server compromise and cleanup, many of the original images stored in:

```
public/images
```

were deleted.

However, Statamic had previously generated and cached image transformations inside:

```
public/img/containers/images
```

These cached folders contained copies of the original images along with resized variants, which made it possible to recover the missing originals.

## Statamic Image Cache Structure

Statamic stores image transformations using the following structure:

```
public/img/containers/images/<original-image-name>/<hash>/<image-file>
```

Example:

```
public/img/containers/images/webchelsea.jpg/
    1b4128682030ead5e6462c9fa9367fe7/
        webchelsea.jpg      (original or large version)
    c9ca854b86165a2dfdfdcb5e7ab31d27/
        webchelsea.jpg      (resized version)
```

Each image folder:

* Is named after the original image file.
* Contains one or more hashed subdirectories.
* Each hash directory contains a processed image version.

Typically:

* The **largest file** corresponds to the original image.
* Smaller files are resized variants generated by Statamic.

## Recovery Strategy

The recovery script performs the following steps:

1. Iterate through all directories in:

```
public/img/containers/images
```

2. For each image directory:

   * Look inside all hashed subdirectories.
   * Locate files matching the same name as the parent directory.

3. Among the matches:

   * Select the **largest file**, assuming it is the closest to the original.

4. Copy the file into:

```
public/images
```

5. Skip files that already exist unless overwrite is enabled.

## Script Usage

### Dry Run (Recommended First)

This shows what will be copied without modifying files.

```
python3 restore_images.py public/img/containers/images public/images --dry-run
```

### Run Recovery

```
python3 restore_images.py public/img/containers/images public/images
```

### Overwrite Existing Files

```
python3 restore_images.py public/img/containers/images public/images --overwrite
```

## Safety Notes

* Always run a **dry run first** to verify results.
* Ensure a backup of the filesystem exists before executing the script.
* This script assumes that the **largest file version corresponds to the original image**.

## Outcome

This process restores missing images from Statamic’s cached image containers and reconstructs the `public/images` directory without requiring a full site backup.

## Date

Recovery performed during the **March 2026 server compromise cleanup**.
